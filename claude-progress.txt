## Key Implementation Details

### Claude API Integration
- Uses Claude Sonnet for PDF document extraction
- Comprehensive extraction prompt for Luxembourg annual accounts
- Zod schema validation for response structure
- Cost tracking per extraction (~$0.20-0.30)

### TP Analysis Logic
- D/E ratio thresholds: 1.5x, 5.67x, 10x
- Spread analysis: Zero (<10bps), Low (<25bps), Negative
- Scoring: A (High), B (Medium), C (Low) based on configurable rules

### Design System
- Dark mode first (slate-900/950 background)
- Typography: Inter (sans), JetBrains Mono (data)
- Color coding: red (high), amber (medium), emerald (low)
- Responsive: Desktop, Tablet, Mobile
